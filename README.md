# Exploratory Data Analysis (EDA) — Roller Coaster Dataset

## Objective
Analyze a real-world roller coaster dataset to uncover patterns, trends, correlations, and key influencing factors using statistical summaries and visualizations.

## Dataset
`coaster_db.csv` contains 1,087 rows and 56 columns in the original dataset.

## Workflow
1. Data Understanding
2. Data Preparation
3. Feature Understanding
4. Feature Relationships
5. Question-based analysis
6. Insights and conclusion

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook.

## Key Insights
- The dataset contains 1,087 roller-coaster records and 56 columns.
- Duplicate coaster records need to be removed before analysis.
- Coaster introductions increased strongly in the late 1990s and early 2000s.
- Most coaster speeds are concentrated around 35–60 MPH.
- Steel coasters generally tend to be faster and taller than wooden coasters.
- Speed and height show a moderate positive relationship.
- Speed and G-force have a weak positive relationship.
- Coaster type is an important factor when comparing speed, height and inversions.

## How to Run
1. Put `coaster_db.csv` in the same folder as the notebook.
2. Install dependencies:
   `pip install pandas numpy matplotlib seaborn jupyter`
3. Open `EDA_Roller_Coaster_Project.ipynb`.
4. Run all cells.
